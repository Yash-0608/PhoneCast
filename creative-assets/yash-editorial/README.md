# Yash — Silent Editorial Edit

A 13-second, vertical 9:16 silent visual edit made from the portrait images generated in the accompanying ChatGPT session.

- Format: MP4 / H.264
- Frame: 720 × 1280
- Frame rate: 24 fps
- Audio: none
- Style: warm editorial grade, gentle push-ins, soft dissolves, minimal title treatment
- Preview: `preview.jpg`

The final MP4 is provided separately in the ChatGPT conversation as `yash_aesthetic_edit_silent.mp4`. It is intentionally not checked into this application repository as a binary media asset; this folder keeps a lightweight preview and edit notes without adding unrelated large media to PhoneCast's application payload.
